Project

Somapura Mahavihara: a computer-graphics recreation of a 1,200-year-old monastery.

Rendering

Built directly on OpenGL

No game engine -- the scene graph, camera, and lighting are hand-written against raw OpenGL and FreeGLUT, which means every visual decision is one I made explicitly.

Scenes

Multiple interchangeable views

Several distinct scenes of the monastery complex, switchable with keyboard input, each with its own camera framing and lighting setup.

Audio

Not a silent render

Ambient audio support layered into the scene, so it's an experience to move through rather than a static 3D model viewer.

Why build a renderer instead of using a game engine

Somapura Mahavihara is a real UNESCO World Heritage site in Bangladesh -- one of the largest known Buddhist monasteries south of the Himalayas. I wanted to recreate it as a computer graphics project specifically because reconstructing an actual historical structure forces you to deal with proportion, layout, and lighting that have to look right, not just render without crashing.

I built it directly on OpenGL and FreeGLUT rather than reaching for a game engine, because the point of the course project was understanding the rendering pipeline itself -- transformations, camera matrices, lighting models -- not learning an engine's abstraction layer on top of it.

Multiple scenes are switchable by keyboard, each a different vantage point or area of the complex, and I added ambient audio support so moving through it reads as an experience rather than a static viewer. It's the project on this list furthest from security work, and I kept it in the list for exactly that reason -- it's real, finished, non-trivial C++ work in a completely different domain.
